Добавить товар

Добавьте строку для каждого размера в наличии (например, «42», «S», «One Size»). Оставьте пустым, если у товара нет вариантов размера — тогда будет использовано поле «Остаток» выше.

Этот товар отмечен как Под заказ — у него нет фиксированного остатка. Покупателям будет показано, что изделие изготавливается вручную по их меркам; поле «Остаток» и строки размеров выше скрыты и не учитываются.

Сначала сохраните товар, затем откройте его снова, чтобы загрузить фото.
